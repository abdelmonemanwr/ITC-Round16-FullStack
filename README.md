# 🚀 DEPI - Round 16 | Full-Stack Course

Welcome to the official repository for **Round 16**. This repository serves as a comprehensive, centralized hub containing all lectures, practical examples, tasks, and materials for both Frontend and Backend development tracks.

---

## 📁 Repository Structure

The project is organized into a clean monorepo architecture:

```text
Round16/
├── 📂 Backend/
│   └── 📂 C#/                  # C# Course materials, OOP, Advanced concepts & projects
├── 📂 Frontend/
│   ├── 📂 HTML/                # HTML fundamentals, forms, and pages
│   └── 📂 CSS/                 # CSS styling, layouts, fonts, and assets
└── 📄 README.md
```

## 🛠️ Tracks & Contents

### 1. Backend Track (`/Backend`)
* **Language:** C# & .NET Core
* **Topics Covered:**
  * Object-Oriented Programming (OOP: Inheritance, Polymorphism, Encapsulation, Abstraction)
  * Generics, Delegates, and Advanced C# Features
  * Database integration, Entity Framework (EF), and LINQ (upcoming)
  * Web APIs & Architecture Patterns (upcoming)

### 2. Frontend Track (`/Frontend`)
* **Technologies:** HTML5, CSS3, JavaScript (upcoming)
* **Topics Covered:**
  * Semantic HTML structure and forms design
  * Modern CSS styling, layouts, and responsive design
  * Interactive components and DOM manipulation with JavaScript (upcoming)

## 📌 Getting Started

To get a local copy up and running, follow these simple steps:

1. **Clone the repository:**
   `git clone https://github.com/abdelmonemanwr/DEPI-R16-CSharp-Course.git`
2. **Navigate to the desired track folder** (`Backend` or `Frontend`) to explore the projects, solutions (`.sln`), and source code.
